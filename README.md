# ZenDen for Devs 🧘💻

A minimal relaxation app for developers built with **Streamlit**.  
ZenDen provides simple visual modes designed to help developers rest their eyes, breathe, and reset during long coding sessions.

Instead of opening social media or doomscrolling, take a **30-second mental break**.

---

## ✨ Features

### ⚫ The Void
Pure black screen for complete visual rest.

- Eliminates all UI distractions
- Ideal for eye relaxation after long screen exposure
- Minimal GPU/CPU load

### 🌿 Stare at Green
Calming animated green gradient.

- Gentle color palette designed for eye relief
- Subtle pulsing animation
- Minimal visual stimulation

### ☁️ Watch Clouds
Slow drifting clouds across a sky gradient.

- Lightweight CSS animation
- Creates a calm visual focus
- Encourages short mindful breaks

### 🫁 Breathe
Guided **box breathing animation (4-4-4-4)**.

- Expanding circle breathing guide
- Text instructions cycle automatically
- Helps reduce stress and reset focus

---

## 🧠 Why This Exists

Developers spend hours staring at screens.  
Short mental resets improve:

- Focus
- productivity
- eye comfort
- stress levels

ZenDen is a **tiny tool to help you pause without leaving your workflow**.

---

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/zenden-for-devs.git
cd zenden-for-devs
```

Install dependencies:

```bash
pip install streamlit
```

Run the app:

```bash
streamlit run app.py
```

---

## 🖥️ Usage

1. Launch the app
2. Choose a **Zen Mode**
3. Relax for 30–60 seconds
4. Exit the mode and get back to coding
